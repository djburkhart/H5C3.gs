Class debug

Paint every box.

H5C3.gs.css includes a debug view. Add the class debug to a grid and each element inside it gets a salmon background and a dotted border. The button adds that class to this page.

From H5C3.gs.css

The rule that does the painting

Put debug on a parent. The universal selector inside it outlines every descendant, which makes nested grids easy to see.

.debug * {
  background: salmon;
  border: 1px dotted grey;
}
