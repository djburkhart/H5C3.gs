A grid you switch on with a label

Columns from a single aria-label.

H5C3.gs is a small grid system for modern browsers. Name two, three, or four columns on an element and the stylesheet builds that many tracks. A child marked as a subgrid does the same thing inside its parent.

Open the 4×4 grid Read the source

01 · Count

Two, three, or four

Those words in an aria-label set the column count. four-column-grid is a four-track grid. Nothing else is required.

02 · Nest

Grids inside grids

Add subgrid to a child label, as in two-column-subgrid. The inner gap is half the outer gap, and the tracks use the parent’s width.

03 · Support

A quiet fallback

@supports keeps the grid off when a browser cannot draw it. js/H5C3.js replaces the page with a short message in that case.

04 · Debug

See every box

The class debug fills each element with salmon and a dotted border. Use it while you check placement, then take it off.

The formula

One calculation for every track

Column width is the target width, minus the gaps, split by the number of columns. --target-width, --column-spacing, and --columns live on :root. Change them once and every grid follows.

(target-width
  - (column-spacing × (columns + 1)))

Mark up a region

The aria-label is the switch. This page uses the same shape: a four-column grid, a two-column banner, and a four-column subgrid for the content.

<section role="region" aria-label="four-column-grid">
  <header role="banner" aria-label="Banner two-column-subgrid">
    <h1>Example heading</h1>
  </header>
  <nav role="navigation" aria-label="Primary four-column-subgrid">
    <a href="#">Link 1</a>
    <a href="#">Link 2</a>
    <a href="#">Link 3</a>
    <a href="#">Link 4</a>
  </nav>
  <main role="main" aria-label="two-column-subgrid">
    <article>
      <h2>Article heading</h2>
      <p>Article text.</p>
    </article>
    <aside role="complementary">
      <h2>Aside heading</h2>
      <p>Aside text.</p>
    </aside>
  </main>
  <footer role="contentinfo">
    <p>&copy; Your copyright info.</p>
  </footer>
</section>
